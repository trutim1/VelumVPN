# Безопасность Velum

## Статус Preview

Текущая поставка Windows — неподписанный GUI Preview, без рабочего VPN-туннеля.
Linux/macOS/mobile возможности подтверждаются отдельно для конкретного релиза.
Не использовать Preview как защиту трафика. Не отключать антивирус, SmartScreen,
брандмауэр и проверку подписей ради запуска. SHA-256 не является подписью или
доказательством безопасности.

## Приватное сообщение об уязвимости

Публичный контакт для приватного сообщения: **anon12anonov@gmail.com**.
Не публикуйте детали уязвимости в issue. Пишите минимальное описание без ключей,
профилей и персональных данных; секреты не пересылайте даже по электронной почте.
Владелец может дополнительно включить GitHub Private Vulnerability Reporting.

Если в репозитории доступна кнопка Security -> Report a vulnerability, можно
использовать её вместо почты. Если кнопки нет, используйте указанный email,
не публичный issue. Гарантированный SLA ответа не заявлен.

Укажите версию/хеш, ОС и минимальный синтетический сценарий. Не отправляйте
реальные ключи, профили `.conf/.vpn`, токены, DPAPI-хранилище, приватные IP/peer
списки, данные кабинета и подписок. Уже раскрытый секрет нужно отозвать/сменить;
удаление сообщения не делает его снова секретным.

## Граница проекта

Репозиторий клиента не предоставляет доступ к рабочему сайту, VPS, платежам,
пользовательским профилям и административным инструментам. Не тестируйте чужие
серверы или пользователей без их отдельного разрешения. Код, который меняет
маршруты/службы/драйверы/ключи, требует независимого review и лабораторных тестов.
